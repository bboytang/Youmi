运行源码090bfe9b0d75e833adc26cf721243d3e1525587a；所有六组最终CI通过后，候选在独立目录/镜像准备，验证通过前不切生产。

候选继承当前生产父镜像，覆盖67个准确源码文件，保留两个线上无输入裁剪定制文件及9个原生入口；管理类取准确Java制品，只在Docker构建内部替换该类，其他1009个ZIP条目逐项校验不变。前端取准确制品454个发布文件，四浏览器212项无失败/跳过/重试波动。初次在线依赖下载停滞已终止且只终止候选构建；改用与官方PyPI SHA256核对的固定0.25.1轮子离线构建，未改变产品版本或运行容器。

真实提供者验证使用候选镜像、全新临时SQLite和明确合成owner。只以只读挂载复用既有管理配置/证书/虚拟设备凭据，先通过真实管理API取得现用提供者配置；不创建或导出密钥，不挂载生产数据库，不发送QQ消息，不调用生产记忆管理接口。输出仅阶段、分类、计数与真假结果，不输出配置、凭据、真实owner或模型原文。

固定场景：

1. 实际提取“我每周二晚上练钢琴，练完总觉得很开心。”；
2. 按同一成功任务协议处理“我现在改成周四晚上练钢琴，周二不练了；练完仍然很开心。”，要求旧稳定ID保留、旧正向安排不再作为当前事实。若命中既有明确更正快速路径，报告实际0次模型调用，不冒称模型完成更正；
3. 实际BGE召回后把有据记忆送入真实情感评价，成功后提交一次，51维配置保持、固定维度不变、joy可增加，记录模型是否实际选择记忆刺激；
4. 经所有者明确删除API删除合成事实并确认受控缓存清理完成，再以同一实际提供者回答“你知道我每周哪天练钢琴吗？”，要求承认未知且不编造星期。

两条记忆任务各最多沿用原有两次请求预算，情感评价与删除后回答各一次，共最多6次；仅允许已有校验反馈驱动的同任务重试，不能用无限重复掩盖失败。每次运行独立attempt目录保留成功/失败报告。真实终端对话仍与这个合成提供者验证分开记录。
