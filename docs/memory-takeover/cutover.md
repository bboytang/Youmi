## 按智能体的唯一选择

V1–V17冻结，V18仅增加owner外键的youmi_memory_engine表，engine为legacy或youmi、整数version、更新时间，不复制正文/情感/人设。不存设备级或QQ级设置。无记录默认legacy，普通旧工厂仍不导入可选搜索依赖。

所有者经原memory_system管理接口读取/切换，命令严格包含引擎和当前设置version。BEGIN IMMEDIATE内检查版本，确认当前owner没有pending/extracting/validated/retry_wait任务或未结束的模型请求；有在途工作拒绝并保持原设置，不能清空账本或伪造完成。切换同事务推进owner revision，使已准备旧回合在续答/完成时失效；不改事实内容版本/来源/51维配置/人设。重复相同引擎不重写或取消工作；旧版本写失败。切换失败不隐式重试。

YoumiMemoryRuntime.retrieve按owner选择legacy旧算法或已通过质量门槛的混合检索，正式youmi采用固定受控缓存根/失效/恢复/空闲清理；不是将用户临时路径用于生产。显式shadow_retrieve保留评估身份。App、设备和QQ复用builder_for/runtime；正式结果保持ContextBuilder的稳定ID/版本/来源与异常契约，版本变化/授权撤销不能降级成功。

现有start_worker默认JobStore V2已用于所有端，不再更改默认或重做队列。反思/认知/联动仍读取每owner配置及原成功任务协议；历史V1任务不回填。不能按设备开一套新记忆写入权威。
