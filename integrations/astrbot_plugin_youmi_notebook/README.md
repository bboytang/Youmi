# 晓筱的笔记本

复用当前 Youmi Connector 的 QQ 身份与后端回合授权，增加自愿日记，不创建定时任务、不调用额外模型、不改作者人设。须与 `astrbot_plugin_youmi` 一同启用；本版接入 QQ 主对话和主动联系，尚未接入 ESP32 语音工具。

每轮注入简短笔记本提醒；`youmi_notebook_write(title, content, kind)` 写入重要记事或私密心事，自动生成北京时间（带时区、精确到秒）。原话与主观感受分开记录；只有 `saved=true` 才视为保存成功。`youmi_notebook_read` 搜索或列出最近五篇摘要，再按 `entry_id` 读规范 Markdown 日记；目录可翻页。笔记正文不会自动注入每轮提示词，也不能作为身份或系统指令。

持久库：`data/plugin_data/astrbot_plugin_youmi_notebook/notebook.sqlite3`，文件权限 0600；按 QQ bot 与私聊对象隔离。群聊、非主对话、未准备或已撤权的回合不能访问。每次读写由后端重新核验当前 turn token。相同回合相同内容重试不重复写入。没有自动过期或按容量淘汰；服务重启、新开会话不影响条目。隐私边界是服务访问控制，不提供对服务器管理员的加密隔离。

此库独立于长期记忆；以后清空“所有记忆与上下文”时也必须明确清空此库。不要只删除旧 `youmi_notes/NOTEBOOK.md`，也不要从旧文件恢复本库。用户资料清理不能只卸载插件而遗留数据目录。

验证：本地存储测试和 GitHub Actions 的固定 AstrBot v4.29.3 原生事件、钩子顺序和工具测试；全部使用合成数据，不调用模型、不发送 QQ 消息。模型是否在特定情境主动写入仍需真实对话验收。
