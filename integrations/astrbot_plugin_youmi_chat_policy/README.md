# Youmi 对话提示词插件

将本目录作为独立 AstrBot 插件安装，要求既有 `astrbot_plugin_youmi` 已启用。

`prompt.txt` 保存用户提供的全文，未修改正文。插件以 UTF-8 读取，只去除文件末尾换行，向本次请求的系统提示词末尾追加；不覆盖既有人格、不修改数据库或聊天历史。

在 AstrBot 后台插件配置中设置 `enabled`，默认关闭。保存生效后只影响后续新请求；已经开始生成的回合不撤回。也可以使用 AstrBot 自身的插件启停开关。

仅处理已有 Youmi 主插件完成认证和准备的前台请求（`youmi_primary_chat` 和 `youmi_turn`），包括使用该入口的 QQ 和 Passport；不附加到定时巡检、主动任务、其他机器人的请求或绕过 AstrBot 的原生模型调用。主插件高优先级准备完成后才追加，避免被其人格装配覆盖。

实际输出取决于厂商和模型，插件不改变供应商规则、工具权限或模型能力。测试验证原文完整性、开关、请求范围及重复调用，不把配置生效声称为特定内容响应已验证。

安装包应包含本目录全部文件，以目录名 `astrbot_plugin_youmi_chat_policy` 安装到 AstrBot 插件目录。代码测试/打包不自动修改生产或开启配置。
